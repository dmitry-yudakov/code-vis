04 / BEFORE YOU BEGIN

An early preview.
A few useful details.

What do I need to run it?

A trusted repository, Git, Node.js 20.9+, npm, and Claude Code or Codex with your own provider authentication and subscription. Follow the repository README for setup. Execution and recovery are currently Linux-oriented.

Does local-first mean fully offline?

No. CodeAI keeps the workspace local, but a provider CLI may send code and context to its provider. CodeAI is a workspace, not a model vendor; your provider’s terms and costs still apply.

Is it ready for my team’s production work?

This is early, rough software intended for trusted repositories and personal use. Review changes and permissions carefully. Real-time multi-human collaboration is planned, and the preview makes no guarantee of correct agent output.

Do I need a headset?

No. Start on desktop. Quest and WebXR are optional; see the README for headset setup and current limitations.
