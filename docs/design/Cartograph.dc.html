Turn 2 · three additions to 1a

Files as a change graph, code as a reveal, ink as a citizen

All three extend 1a rather than replacing it — same shell, same node vocabulary. 2a is your review idea: real files with added/modified/removed parts, wired into one connected graph with coverage tracking so no hunk goes unseen. 2b makes source a third reveal depth inside a node, with edges anchored to lines. 2c answers the two open questions: capabilities carry a provenance mark (you drew it · agent drafted · inferred from code · confirmed), and ink lives on the same canvas as laid-out nodes — its own layer, promotable to real nodes, drawable over anything the agent produced.
